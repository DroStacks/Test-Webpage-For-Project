# HealthBridge Medical — Test Webpage Project

HealthBridge Medical is a personal, work-in-progress project focused on building and deploying a mock educational healthcare website. The project is being developed as a way to practice full-stack web development, Linux server administration, database management, networking, and web deployment.

## Project Purpose

This repository is public so that potential employers and hiring managers can review the code, project structure, and technologies used throughout development. The goal is to demonstrate my practical experience building a website from the ground up rather than relying entirely on managed website-building platforms.

## Disclaimer

HealthBridge Medical is a fictional organization created solely for educational and portfolio purposes. The website does not provide real medical services and is not intended to collect or store real patient or medical information.

## Hosting Environment

The website is currently hosted on a locally managed Ubuntu Server virtual machine rather than a third-party cloud provider such as AWS or Microsoft Azure.

The local environment is designed to mimic many aspects of a cloud-hosted Linux web server. This allows me to gain hands-on experience with server configuration, networking, web hosting, security, databases, and application deployment while maintaining control over the entire environment.

## Technologies Used

* **HTML** — Website structure and page content
* **CSS** — Styling, layout, and responsive design
* **JavaScript** — Client-side functionality and interactivity
* **PHP** — Server-side processing and backend functionality
* **MySQL** — Database management and storage
* **Apache** — Web server used to host the website
* **Ubuntu Server** — Linux operating system hosting the web environment
* **Git & GitHub** — Version control, source-code management, and project tracking
* **SSH** — Remote administration and management of the Linux server

## Current Features

The project currently includes a functional Apache/PHP web environment and MySQL database integration. The website contains multiple pages and backend functionality designed to demonstrate how a basic full-stack website communicates between the frontend, PHP backend, and database.

The server environment is also managed through Linux and SSH, allowing the project to provide experience beyond simply writing the website's frontend code.
